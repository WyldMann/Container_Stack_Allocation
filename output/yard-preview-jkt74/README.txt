JKT74 yard preview
Extract this ZIP and open index.html in a browser. The page works offline.
Click a block on the map or its tab, then click a stack to inspect its tiers and parameters.

This is a snapshot of the current JKT74 layout, yard plan and containers accepted by the yard model.
The HTML includes the same snapshot data as the CSVs. Editing the CSVs does not change this preview.

yard-blocks.csv: Block coordinates, dimensions and totals.
yard-stacks.csv: One row per stack with occupancy, capacity and parameter IDs.
yard-tiers.csv: One row per tier position, including empty positions. A 40 ft container appears
in both occupied slots. Use container_id for unique counts and anchor_slot to locate its anchor.
yard-parameters.csv: Definitions of the assigned parameters. Weight values use the source units.
